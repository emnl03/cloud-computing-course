Cloud Concepts Reflection

In my daily life, I rely on several cloud-based services that make tasks more convenient and efficient. Among these are Google Drive, Messenger, and GCash. These platforms show how cloud computing supports communication, storage, and financial transactions seamlessly.

Google Drive is an example of Software as a Service (SaaS) under the Public cloud deployment model. It allows users to store, manage, and share files online without installing or maintaining any infrastructure. Since it is accessible to anyone with an internet connection and a Google account, it fits the public cloud model.

Similarly, Messenger is also a SaaS application deployed on a Public cloud. It provides messaging and communication services without requiring users to manage servers or software, making it convenient and widely accessible.

GCash is also SaaS, but it can be considered part of a Hybrid cloud deployment model. While users access it publicly, it likely combines public and private cloud systems to ensure secure financial transactions and compliance with regulations. This balance of accessibility and security makes hybrid deployment suitable for financial services.

Version control is critical when managing cloud infrastructure, especially in team environments. Tools like Git help track changes in code and configurations, ensuring updates are documented and reversible. This reduces the risk of errors that could disrupt cloud systems.

GitHub enhances collaboration by allowing teams to work on shared repositories, create branches, review code, and safely merge updates. It helps prevent mistakes through version tracking and code reviews. Overall, GitHub improves organization, accountability, and reliability in managing cloud-based projects.
